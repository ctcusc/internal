# CTC typography

Local fonts shared with the CTC public website:

- **Alte Haas Grotesk** — Yann Le Coroller, distributed free; used for interface text.
- **Redaction 50** — Titus Kaphar and Reginald Dwayne Betts with MCKL, released free; used on the sign-in page.

Source assets come from `ctcusc.com/src/fonts`. Local loading keeps the app independent of a font CDN.
